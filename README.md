# CIRNET Embedded Hardware

[English](docs/en/index.md) · [Tiếng Việt](docs/vi/index.md) · [Changelog](docs/changelogs/README.md)

The Embedded Hardware repository owns the Lab-First controller RTL, reserved instrument interfaces and behavioral testbenches. This generation begins at `0.3.0-dev.1`. The logical FPGA envelope remains `1.0-scaffold`. Physical firmware and transport remain `UNAVAILABLE`.

See the [scaffold guide](docs/en/scaffold.md) and [verification guide](docs/en/verification.md).
